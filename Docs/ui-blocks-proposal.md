# dennokoworks UI ブロック・画面パターン案

2026-11-06 · dennoko
前提: [ui-components-proposal.md](ui-components-proposal.md)（部品単位の案）。本案はその部品を組み合わせた 1 段大きい単位（カード・画面・シーン操作 UI）を定義する。**スキルへ反映済み**（2026-11-06。`.claude/skills/dennokoworks_color_schema/blocks/`。標準ヘッダー・標準フッターは `DennokoTheme.uss` ⑪ と `references/window-guide.md`）。以降はスキル側を正とし、本書は経緯の記録として残す。

Unity 上のモック: UI Design Test（`dennokoworks/UI_design_test`）の末尾の 3 セクション。「SCREEN PATTERNS」で P1〜P5 を切り替えて表示し（状態の切り替えは枠内の ⋮ →「モック」）、「SCENE UI」のボタンでシーン操作 UI（S1〜S6）をシーンに出す。パイメニューはテンプレート化した（[radial-menu-template.md](radial-menu-template.md)）。コードは `Editor/Mock/`、提案中のクラスは `Editor/Mock/UI/DennokoBlocks.uss`（ウィンドウ）と `DennokoSceneUI.uss`（シーン）。

## 概要と方針

部品案では「トップバー」「対象を選ぶ行」のように 1 行・1 要素の単位を定義した。実際にツールを作るときに毎回迷うのは「どのカードをどの順に置くか」「主ボタンはいつ何になるか」「シーン上の操作 UI をどこに出すか」なので、その判断までを含めた大きい単位を用意する。

| 層 | 単位 | 例 | 決めること | 定義元 |
| --- | --- | --- | --- | --- |
| L0 | トークン・基本クラス | `--dennoko-surface-1`、`.dennoko-card` | 色・余白・文字 | DennokoTheme.uss（既存） |
| L1 | 部品 | トップバー、対象を選ぶ行、アイコンボタン | 見た目と 1 つの動作 | 部品案 |
| L2 | ブロック | 対象カード、設定カード、リストカード | 部品の並び、状態ごとの出し分け、空の状態 | **本案 §2** |
| L3 | 画面パターン | 変換、手順、一覧編集、シーン作業、コンポーネント編集 | カードの並び順、主ボタンの移り変わり、Idle / Working | **本案 §1** |
| L3 | シーン操作 UI | ツールバー、ツールパネル、ラジアル、シーン描画の色 | SceneView 上の置き場所、編集セッションの始め方と終わり方 | **本案 §3** |

- 新しいツールは「画面パターンを 1 つ選ぶ → ブロックを並べる → 足りない所だけ部品で組む」の順で作る。スキルのワークフローもこの順にする。
- ブロックも部品と同じく USS クラス + UXML 雛形 + 必要なら小さな C# ヘルパーで、各ツールへコピーして使う。
- 部品案の「主ボタンは 1 つ」を、パターン側で「どの状態で何が主ボタンか」まで決める。
- シーン操作 UI もウィンドウと同じテーマ（Surface / Outline / selection 色）を使い、ツールごとの独自色（緑枠・緑の太字ヒント・ピンクのミラー円など）をやめる。

## 1. 画面パターン

### 1.0 パターンの選び方

| パターン | 一言で | 判定の質問 | 該当ツール |
| --- | --- | --- | --- |
| P1 変換 | 入力を選び、設定して、1 回出力する | 出力ボタンを押したら作業が終わるか | NormalMapGenerator / FastCurvatureBaker / MatcapMaker / FolderTreeExporter / UniTex / BoxWeightTransfer / SocksTuku-ru |
| P2 手順 | 前の手順の結果を次の手順で使う | 順番を入れ替えると結果が変わるか | HairChimera |
| P3 一覧編集 | たくさんの項目を見て、絞って、まとめて変える | 画面の主役が一覧か | BatchRenamer / DenEmo / FolderCleaner / DennokoMAT |
| P4 シーン作業 | ウィンドウで始め、作業はシーンでする | 作業の大半がシーンのクリック・ドラッグか | MaskMakerV4（一部：MeshSplitter / HairChimera のシーン選択） |
| P5 コンポーネント編集 | Inspector から編集モードに入り、結果をコンポーネントに保存する | 設定をシーン上のコンポーネントに持つか | DennokoMeshEditor / DennokoNormalEditor / DenLattice / CableGenerator |

迷ったときの優先順：シーン操作が主なら P4 / P5、一覧が主なら P3、手順があるなら P2、どれでもなければ P1。

### P1 変換

```
┌ Tool Name  v1.2.0 ↻            EN ? ⋮ ┐  トップバー
├───────────────────────────────────────┤
│ ┌ 入力 ───────────────────────────┐  │  B1 対象カード
│ │ [Texture            ] [選択から] │  │
│ └─────────────────────────────────┘  │
│ ┌ 設定 ────────────────── ? Reset ┐  │  B2 設定カード（1〜3 枚）
│ │ ...                             │  │
│ │ ▸ 詳細  [512] [Linear]          │  │  閉じているときは値のチップで要約
│ └─────────────────────────────────┘  │
│ ┌ プレビュー ─────────────────────┐  │  B3 プレビューカード（任意）
│ └─────────────────────────────────┘  │
├───────────────────────────────────────┤
│ 出力先 …/Textures   [選択…]  ☐ 上書き │  B5 出力（ドック）
│ [              生成              ]    │  フッター
│ 保存: Body_normal.png                  │  ステータスバー
└───────────────────────────────────────┘
```

- 主ボタンは常に 1 つで、文言は動詞 1 語（「生成」「出力」「ベイク」）。入力が無い間は無効にし、ツールチップに理由を出す（「入力を選んでください」）。
- 入力が無くても設定カードは表示する（先に設定だけ決めたい人がいる）。プレビューは空の状態にする。
- 出力したらステータスバーに `保存: <ファイル名>` を出し、クリックで Project ビューの該当ファイルを Ping する。
- 入力が「1 つ」ではなく「一覧」になったら P3 として作る（バッチ処理）。

### P2 手順

```
┌ Tool Name  v1.0.0 ↻            EN ? ⋮ ┐
├───────────────────────────────────────┤
│ [1 切り分け ✓][2 パーツ][3 調整][4 出力] │  手順タブ（.dennoko-tabbar--steps）
├───────────────────────────────────────┤
│  その手順のカードだけ                   │  スクロール領域
├───────────────────────────────────────┤
│ [← 戻る]   [   次へ：パーツ   →   ]     │  フッター（戻る = Secondary）
│ Ready                                  │
└───────────────────────────────────────┘
```

- 主ボタンは「次へ：<次の手順名>」。最後の手順だけ「出力」になる。部品案のとおり、フッターは 1 つでタブ切替に合わせて文言と処理を差し替える。
- 前の手順をやり直したら、それより後の手順の ✓ を外し、その手順を開いたときに警告行「前の手順が変わりました。もう一度確認してください」を出す。
- 手順は 3〜5 個まで。6 個以上になる場合は、手順をまとめるか P1 を複数のタブに分ける。

### P3 一覧編集

```
┌ Tool Name  v1.0.0 ↻            EN ? ⋮ ┐
├───────────────────────────────────────┤
│ ┌ 対象 ───────────────────────────┐  │  B1（フォルダ / ルートオブジェクト）
│ └─────────────────────────────────┘  │
│ [🔍 検索          ✕] [変更あり][警告] 12/480 │  B4 の検索行（固定）
│ ┌─────────────────────────────────┐  │
│ │ 行 / 行 / 行 …（ListView）       │  │  B4 リスト（ここだけが伸びる）
│ └─────────────────────────────────┘  │
│ ┌ 設定 ───────────────────────────┐  │  B2（一括操作の内容。折りたたみ可）
│ └─────────────────────────────────┘  │
├───────────────────────────────────────┤
│ 12 件を変更        [元に戻す] [ 一括適用 ] │  フッター（情報欄 + 主ボタン）
│ Ready                                  │
└───────────────────────────────────────┘
```

- **このパターンだけ、ページ全体の ScrollView を使わない。** ListView を ScrollView に入れると二重スクロールになり、仮想化も効かなくなるため、リストカードを伸びる領域にする。
- 実行すると戻せない操作（削除・上書き）は、実行前に B6 確認カードで差分を見せる。主ボタンにせず、Secondary + 確認ダイアログにする（部品案のフッター規則）。
- 一覧の件数と選択数はフッターの情報欄にだけ出す（検索行の `12/480` は「表示中 / 全体」）。

### P4 シーン作業

状態は **Idle（未開始）と Working（作業中）の 2 つだけ**。出力は状態ではなくイベントとして扱い、出力後もそのまま作業を続けられる（MaskMakerV4 の §3 を一般化）。

| 状態 | ウィンドウ | シーン | 主ボタン |
| --- | --- | --- | --- |
| Idle | B1 対象カードと主ボタンだけ。他のカードは描画しない | 何も出さない | 「作業開始」 |
| Working | B7 作業中バナー + 作業用カード（設定・プレビュー・出力） | §3 のシーン操作 UI | 「出力」（または「完了」） |

- 開始の入口はウィンドウの主ボタンと Hierarchy の右クリックメニュー。**シーンに開始ボタンは置かない**（このツールを使わない作業の邪魔になる）。
- 終了の入口はウィンドウのバナーの「終了」、シーンのツールパネルの ✕、Esc の 3 つ。どれも同じ終了処理を呼ぶ。
- 自動終了・自動保存などの約束は §3.4 セッション規約に従う。

### P5 コンポーネント編集（Inspector）

```
Idle                                         Working
┌ Inspector: Den Mesh Editor ─────────┐      ┌ Inspector: Den Mesh Editor ─────────┐
│ v1.0.0 ↻                    EN ? ⋮ │      │ v1.0.0 ↻                    EN ? ⋮ │
│ [       シーンで編集       ]        │      │ ● 編集中  Body   Esc で終了  [終了] │  B7
│ ┌ ブラシ ───────────────────────┐  │      │ ┌ ブラシ ───────────────────────┐  │
│ │ 半径 / 減衰 / ミラー           │  │      │ │ 半径 / 減衰 / ミラー（同期）    │  │
│ └───────────────────────────────┘  │      │ └───────────────────────────────┘  │
│ ┌ 編集の一覧 ────────────────────┐  │      │ ┌ 編集の一覧 ────────────────────┐  │
└─────────────────────────────────────┘      └─────────────────────────────────────┘
```

- Inspector ではコンポーネント名が Unity の見出しに出るので、トップバーはツール名を省いた細い版（`.dennoko-appbar--compact`：バージョン + ↻ と右側のアイコン）にする。
- Idle の主ボタンは「シーンで編集」。Working ではバナーに置き換わり、Inspector に主ボタンは無い（作業の本体はシーン）。
- シーンのツールパネルと Inspector の両方に同じ設定（半径など）が出る。値は 1 か所（コンポーネント）だけに持ち、どちらで変えてももう片方が即座に追従する。
- 選択を外す・別のオブジェクトを選ぶと Inspector が消えるので、セッションは Inspector の寿命に依存させない（§3.4）。

## 2. ブロック（カード単位）

| # | ブロック | クラス | 使うパターン | 置き換え対象 |
| --- | --- | --- | --- | --- |
| B1 | 対象カード | `.dennoko-target-card` | 全部 | 各ツールの「対象」「入力」カード、MaskMakerV4 の TargetCard |
| B2 | 設定カード | `.dennoko-options-card` | 全部 | 各ツールの設定カード、`.dennoko-toggle-header` のセクション |
| B3 | プレビューカード | `.dennoko-preview-card` | P1 / P2 / P4 | DennokoMAT / HairChimera / NormalMapGenerator / UniTex / MaskMakerV4 の UV ビュー |
| B4 | リストカード | `.dennoko-list-card` | P3（P2 の一部） | DenEmo / BatchRenamer / DennokoMAT の一覧 |
| B5 | 出力（カード / ドック） | `.dennoko-output-card` / `.dennoko-output` | P1 / P2 / P4 | NormalMapGenerator の OUTPUT、MaskMakerV4 の OutputCard + サマリ |
| B6 | 実行前確認カード | `.dennoko-review-card` | P3 | BatchRenamer のプレビュー、FolderCleaner の削除候補 |
| B7 | 作業中バナー | `.dennoko-session-banner` | P4 / P5 | MaskMakerV4 の対象カード（作業中）、各 Inspector の「編集中」表示 |

### B1 対象カード

ツールが何に対して働くかを決めるカード。常にスクロール領域の先頭に置く。

```
┌─────────────────────────────────────┐
│ [Body (SkinnedMeshRenderer)] [選択から] │  行 1：対象を選ぶ行（部品）
│ [Body_skin ▼]  [UV0 ▼]               │  行 2：下位の選択（あるときだけ。ラベルは省略可）
│ 頂点 12,480 · Read/Write ✓           │  行 3：情報行（Tertiary、任意）
└─────────────────────────────────────┘
```

| 状態 | 表示 |
| --- | --- |
| 空 | 行 1 だけ。ObjectField のプレースホルダに「Renderer を選択」など対象の種類を書く。主ボタンは無効 |
| 指定済み | 行 1〜3 |
| 問題あり | 行 3 の代わりに警告行 + 修正ボタン 1 つ（例：「Read/Write が無効です [有効にする]」）。自動で直せるものは直して情報行で知らせる |
| 候補が複数 | ルートオブジェクトを選んだとき、行 1 の下に子 Renderer の一覧（アイコン + 名前）を出し、クリックで決定（MaskMakerV4 の挙動） |
| 作業中（P4） | ObjectField をやめて「アイコン + 名前 ▼」の表示にし、▼ で対象を切り替える。B7 バナーと一体にしてもよい |

- Hierarchy / Project の選択からの自動入力は、**欄が空のときだけ**行う。指定済みの値は勝手に変えない（未決事項）。
- 見出しは付けない（中身で対象と分かる）。P1 で入力が 2 つ以上あるときだけ「入力」「参照」などの見出しを付ける。

### B2 設定カード

```
┌ ブラシ ──────────────────────── ? ↺ ┐  見出し + ヘルプ + このカードだけのリセット
│ 半径     ━━━━━●━━━━━   [0.025]       │
│ 減衰     [滑らか][直線][鋭い][一定]   │
│ ☑ ミラー                              │
│ ▸ 詳細   [X 軸] [ルート基準]          │  閉じているときは値のチップで要約
└─────────────────────────────────────┘
```

- 1 枚に置く行は 7 行まで。超えるならカードを分けるか、「詳細」に入れる。
- 「詳細」は閉じた状態を既定にし、閉じている間は今の値を `.dennoko-summary-chip`（アイコン + 値）で見出し行に並べる。初期値のままの項目はチップを出さない。
- 見出し右の ↺ はそのカードだけを初期値に戻す。Undo で戻せるので確認ダイアログは出さない（トップバーの「設定を初期値に戻す」は全体なので確認を出す）。
- トグル付きセクション（OFF なら中身を使わない）は見出し行にトグルを置き、OFF のときは中身を折りたたむ。
- ラベル幅はカード内で揃える（部品案の field label 幅）。値だけで意味が通る項目はラベルを省く。

### B3 プレビューカード

```
┌─────────────────────────────────────┐
│                          [⤢][◐][⧉] │  右上に重ねるツールバー（アイコンボタン 3 個まで）
│          （プレビュー）              │
│                                     │
├─────────────────────────────────────┤
│ 1024 × 1024 · 0.4 秒前に更新          │  情報行（Tertiary）
└─────────────────────────────────────┘
```

| 状態 | 表示 |
| --- | --- |
| 空 | 中央に案内 1 行（「入力を選ぶとここに表示されます」）。ドロップを受けるならドロップ領域を兼ねる |
| 計算中 | 前の画像を残したまま、上端に細い進捗バー。前の画像が無ければ中央に「計算中…」 |
| 古い | 設定を変えたが未更新のとき、右上に「更新」チップを出す（重いプレビューのみ） |
| エラー | 中央に原因 1 行（error-text） |

- 更新の方針は重さで決める：軽い → 値の変更ごとに即時、中くらい → 最後の変更から 300ms 後、重い → 手動の「更新」と「古い」表示。
- 縦横比は「正方形」「入力に合わせる」の 2 種類。カードの幅に合わせて高さを決め、ウィンドウを縮めたら一緒に縮む。
- 大きく見たいツールは右上のツールバーに「別ウィンドウで開く ⧉」を置く（MaskMakerV4 の UVLayoutWindow）。

### B4 リストカード

```
[🔍 検索            ✕] [変更あり] [警告]          12 / 480
┌─────────────────────────────────────────────────────┐
│ ☐ [icon] 名前                補足           [⋮]     │  行テンプレート（部品）
│ ☑ [icon] 名前                補足           [⋮]     │
└─────────────────────────────────────────────────────┘
```

- 検索行は伸びる領域の外（リストの上）に固定する。右端の数字は「表示中 / 全体」。
- 空の状態は 2 種類を区別する。対象が無い →「フォルダを選ぶと一覧が出ます」+ 次の操作のボタン。絞り込みで 0 件 →「一致する項目がありません [絞り込みを解除]」。
- 行の右端に置く操作は 2 個まで。それ以上は ⋮ のメニューに入れる。一括操作は行に置かずフッターに置く。
- クリックで選択、ダブルクリックで Ping / 開く、Space で選択の ON/OFF、↑↓ で移動。複数選択は Ctrl / Shift。

### B5 出力（カードとドック）

部品案の `.dennoko-output`（フッター直上のドック）に加え、出力設定が多いツール用にカード版を用意する。

| 出力設定の量 | 置き方 | 例 |
| --- | --- | --- |
| 2 行まで（出力先 + 上書き程度） | ドック（`.dennoko-output`）だけ。常に見える | NormalMapGenerator / UniTex |
| 3 行以上（名前・解像度・チャンネルなど） | スクロール領域の最後に出力カード、ドックには要約チップだけ（`[📁 Textures] [2048] [RGBA]`）。チップをクリックするとカードへスクロール | MaskMakerV4 |

- ドックの要約チップはカードと同じ値を出す。カードが画面内に見えているときはチップを隠す（同じ情報を 2 か所に出さない）。

### B6 実行前確認カード

取り消せない・影響が大きい操作の前に、何が起きるかを一覧で見せる。

```
┌ 確認 ─────────────── 変更 12 · 変更なし 3 · 衝突 1 ┐
│ Hair_01.png   →  Hair_Base_01.png                  │
│ Hair_02.png   →  Hair_Base_02.png                  │
│ ⚠ Hair_03.png →  Hair_Base_01.png（名前が重複）      │
└────────────────────────────────────────────────────┘
```

- 見出し行に種類別の件数を出し、件数をクリックするとその種類だけに絞る。
- 衝突・エラーがあるときは主ボタンを無効にせず、確認ダイアログに件数を出す（「1 件は衝突のためスキップされます」）。
- 削除は「削除」ではなく「ゴミ箱へ移動」にできるならそうする（OS のゴミ箱 / `AssetDatabase.MoveAssetToTrash`）。

### B7 作業中バナー

シーンで作業中であることを、ウィンドウ・Inspector 側に示す 1 行。P4 / P5 の Working で、スクロール領域の外（トップバー / タブの直下）に固定する。

```
│ ● 編集中  Body        Esc で終了   [終了] │
```

- 背景は `--dennoko-selection-bg`、左端に 3px の `--dennoko-selection-border`。「●」も selection 色。
- 対象名をクリックすると SceneView をその対象にフレームする。
- 「終了」は Secondary ボタン。シーンのツールパネルの ✕・Esc と同じ処理を呼ぶ。
- 同じ情報はシーン側のツールパネル（S2）のセッション行にも出す。ウィンドウとシーンのどちらを見ていても作業中と分かるようにするため、ここは重複を許す。

## 3. シーンビュー操作 UI

ツール操作中に SceneView 上に出す UI。DennokoMeshEditor の操作パネルや MaskMakerV4 のツールバー・ラジアルメニューを、全ツール共通の部品として定義する。

### 3.0 現状調査

| ツール | 方式 | 中身 | 見た目 |
| --- | --- | --- | --- |
| DennokoMeshEditor / DennokoNormalEditor / DenLattice | IMGUI の自作パネル（`Handles.BeginGUI` + `GUILayout.BeginArea`）。既定は右下、見出しの ⠿ で自作ドラッグ | 半径スライダー、減衰、ミラー ON/OFF、操作ヒント 2 行、NDMF の警告。NormalEditor は効果スライダー 4 本、DenLattice は格子数・ミラー軸 XYZ・ボックスモード（移動 / 回転 / 拡縮）・ケージのリセット | 黒半透明 + 緑 2px 枠。ON は緑背景、ヒントは緑の太字 12〜15px。幅 330px・高さ固定 |
| MaskMakerV4 | UI Toolkit。`Overlay` + `ITransientOverlay` のカプセル型ツールバーと、SceneView の `rootVisualElement` に重ねた HUD（ラジアル・トースト・カーソルヒント） | モード / 選択の単位 / ツール / トグル / Undo / 出力 / 選択数。C 長押しで 8 方向のラジアル | DennokoTheme + `DennokoSceneUI.uss`（MaskMakerV4 内のスキルのコピーにだけ存在） |
| MeshSplitter / HairChimera | `duringSceneGui` で選択面を塗る | クリックで面・パーツを選ぶ（ウィンドウ側のトグルで ON） | 選択 `#9dd2ff`、ホバー `#ffb74d` を各自で定義 |
| CableGenerator | Inspector のピッキングモード | クリックした点と法線、ラベル | IMGUI |
| BoxWeightTransfer / SocksTuku-ru / DenEmo | シーンに描くだけ（操作 UI なし） | ボックス、生成形状のプレビュー、頂点ガイド | 各自の色 |
| HowManyPolygons | 常に出す情報表示（IMGUI） | ポリゴン数と段階の色 | 黒半透明 + 緑 / 橙 / 赤 |

見えている問題：

- IMGUI パネルの 3 ツールは、ドラッグ・画面内への収め込み・枠の描画・Layout 時の状態固定がほぼ同じコードの複製になっている。
- 「編集中」の示し方が緑枠だけで、緑はテーマでは「成功」の色。ヒントは常設で文字が多い（「※ Escキーで編集終了（選択中は選択解除）」）。
- シーンに描く色がツールごとに違う：ホバーは橙・黄・白縁、選択は水色、ミラー側はピンク。
- シーン UI のガイド（sceneview-guide.md）と `DennokoSceneUI.uss` が MaskMakerV4 内のスキルのコピーにしかなく、UI_Design 側のスキルと分かれている。

### 3.1 3 つの置き場所の分担

MaskMakerV4 の「3 領域の役割分担」を全ツールの規則にする。

| 置き場所 | 担当すること | 置かないもの |
| --- | --- | --- |
| ウィンドウ / Inspector | 開始・終了、対象、作業の前後に決める設定、出力 | 作業中に何度も変えるもの |
| シーンの直接操作 | クリック・ドラッグ・ホイール（作業の本体） | 設定値の変更 |
| シーン操作 UI（本章） | 作業中に切り替えるモード・ツール・トグル・数値、今の状態の表示、終了 | 出力先など作業の前後に決める設定 |

- **状態は 1 か所（`YourSceneToolState` またはコンポーネント）にだけ持つ。** ウィンドウ・シーン操作 UI・ショートカットはどれもそこを書き換え、`Changed` を受けて表示を読み直す。

### S1 シーンツールバー（カプセル）

MaskMakerV4 の `CapsuleOverlay` を標準にする（仕様は MaskMakerV4 版 sceneview-guide.md のまま）。

```
╭──────────────────────────────────────────────────────────────╮
│ [選][塗] │ [島][パーツ][面] │ [⇋] │ [👁][◎] │ [↶][↷][🗑] │ [💾]  12/480 │
╰──────────────────────────────────────────────────────────────╯
```

- 高さ 32px・角丸 16px、Surface1 + Outline。まとまりは `.dennoko-segment`（右側の縦線）で区切る。
- ボタンは**アイコンのみ**（26px 角）。名前とキーはツールチップ（`"ブラシ  B"`）。文字の選択肢は `.dennoko-choice`（1 ボタン 3 字まで）。
- 現在値・ON は selection 色の枠（`.dennoko-button-active`）。実行系の成功は 2 秒だけ緑枠（`.dennoko-success-frame`）。
- 常に出す数値は右端の 1 つだけ（選択数など）。
- モードで中身を差し替えるときは同じ位置を差し替え、ボタンの数を変えない。
- ボタンは 12 個まで。それ以上はラジアル（S3）かパネル（S2）へ。
- 既定の位置は左の列の下端（`DockZone.LeftColumn` / `DockPosition.Bottom`）。

### S2 シーンツールパネル（新規）

DennokoMeshEditor / DennokoNormalEditor / DenLattice の IMGUI パネルを置き換える、数値を扱う作業用パネル。Unity の Overlay（パネル表示）にすることで、自作のドラッグ・画面内への収め込み・位置の記憶を Unity に任せる。

```
╭ Mesh Editor ──────────────────── ⌄ ╮  ← Unity の Overlay 見出し（名前・ドラッグ・折りたたみ）
│ ● 編集中  Body                [✕] │  ← セッション行（対象名 + 終了）
│ ───────────────────────────────── │
│ 半径  ━━━━━━●━━━━━━━   [0.025]     │  ← コンパクトスライダー
│ 減衰  [滑らか][直線][鋭い][一定]    │  ← 選択肢グループ
│ ミラー [X][Y][Z]                    │  ← トグル（ON は selection 色の枠）
│ ───────────────────────────────── │
│ [Wheel] 半径   [Esc] 終了           │  ← キーヒント（Tertiary、2 組まで）
│ ⚠ NDMF プレビュー未取得             │  ← 警告行（必要なときだけ。全文はツールチップ）
╰───────────────────────────────────╯
```

構成要素：

| 要素 | クラス | 見た目と動作 |
| --- | --- | --- |
| セッション行 | `.dennoko-scene-panel__session` | selection 色の ● + 「編集中」+ 対象名（省略表示）+ ✕（アイコンボタン）。✕ は Esc と同じ終了処理。対象名クリックでフレーム |
| コンパクトスライダー | `.dennoko-scene-row` | ラベル 44px（11px・Tertiary）+ スライダー（伸びる）+ 数値欄 48px。ホイールなどシーン側で変えた値も即座に反映する |
| 選択肢グループ | `.dennoko-choice-group` | `.dennoko-choice` を隙間なく並べ、現在値に selection 色の枠。enum はドロップダウンにせずこれを使う（4 つまで。5 つ以上はドロップダウン） |
| トグル | `.dennoko-choice` / `.dennoko-icon-button` | ON で selection 色の枠。ON/OFF を文字（「ミラー: 有効 (ON)」）で書かない |
| 1 回適用スライダー | `.dennoko-scene-row--impulse` | ドラッグした量だけ効果をかけ、離すと確定して 0 に戻る（NormalEditor の効果スライダー）。数値欄は出さず、ドラッグ中だけつまみの横に % を出す |
| 小見出し | `.dennoko-scene-panel__section` | 10px・Tertiary。行のまとまりが 2 つ以上あるときだけ（「効果」「ボックス」） |
| キーヒント | `.dennoko-keyhints` + `.dennoko-keycap` | キーキャップ（Surface2 + Outline、10px、角丸 3px）+ 説明（Tertiary）。常設は 2 組まで。残りはツールチップと S4 のキー一覧へ |
| 警告行 | `.dennoko-scene-panel__warning` | `--dennoko-status-warning-bg` + ⚠ + 1 行（30 字まで）。全文はツールチップ |

規則：

- パネルに置くのは「作業中に変える値」と「終了」だけ。出力・保存・作業の前後に決める設定は置かない。
- 幅は 240px 固定、高さは中身に合わせる。行は 8 行まで。
- 既定の位置は右の列の下端（今の DennokoMeshEditor と同じ右下）。S1 と併用するツールでは S1 が左下、S2 が右下。
- スライダーのドラッグは 1 回で Undo 1 段にまとめる。UI Toolkit の Slider はドラッグ中も `ChangeEvent` を出し続けるので、最初の変更で Undo グループを開き、`PointerCaptureOutEvent` で `CollapseUndoOperations` する（今の IMGUI 版と同じ考え方）。
- 「編集中」を枠の色で示すのはやめ、セッション行と「作業中だけ表示される」ことで示す（`ITransientOverlay`）。

今のパネルからの置き換え：

| ツール | 今 | 置き換え後 |
| --- | --- | --- |
| DennokoMeshEditor | 半径スライダー、減衰 EnumPopup、ミラー ON/OFF の大きいボタン、ヒント 2 行、NDMF 警告 | 半径（コンパクトスライダー）、減衰（選択肢グループ）、ミラー（トグル）、キーヒント 2 組、警告行 |
| DennokoNormalEditor | 上記 + 効果スライダー 4 本 | 上記 + 小見出し「効果」+ 1 回適用スライダー 4 本（選択が無いときは無効） |
| DenLattice | 格子数、ミラー軸 XYZ、ボックスモード ON/OFF、移動 / 回転 / 拡縮、ケージのリセット | 格子数（整数 3 つの行）、ミラー（XYZ トグル）、モード（選択肢「ケージ / ボックス」）、ボックス時だけ「移動 / 回転 / 拡縮」（W / E / R をヒントに）、リセットは小見出し右の ↺ |

### S3 ラジアルメニュー

MaskMakerV4 の実装（`YourRadialMenu`）を標準にする。仕様は MaskMakerV4 版 sceneview-guide.md のまま、全ツールで揃える点だけを決める。

- キーは全ツール共通で **C 長押し**（`ClutchShortcut` + セッション中だけ有効にするタグ）。ユーザーは Shortcut Manager で変更できる。
- 項目は常に 8 個。空きは薄く表示して選べなくする。↑ は「モード切替」に固定する（モードが無いツールは ↑ を空ける）。
- 中心には向いている項目の名前だけ（8 字まで）。0.6 秒動かさずに押し続けるとキーを表示する。
- Undo / Redo のように Ctrl+Z で済むものは入れない。実行はメニューを閉じてから行う。
- 切り替える項目が 4 個以下のツールでは使わない（ツールバーとキーで足りる）。

### S4 シーンフィードバック

| 種類 | 出る場所 | 内容 | 消え方 |
| --- | --- | --- | --- |
| トースト | シーンから実行したときはカーソルのすぐ脇、それ以外は SceneView 下端の中央 | アイコン + 1 行（30 字まで）+ 操作ボタン 1 つまで（例：「Body_mask.png [適用]」） | 4 秒。ホバー中は消えない |
| カーソルヒント | カーソルの右下 12px | 1 行。迷っていそうなときに次の操作を案内（「クリックで選択」「X で左右同時」） | 操作したら消える。各ヒント 3 回まで |
| 修飾キーのバッジ | カーソルの右下 | Shift / Ctrl を押している間、足す（+）/ 引く（−）をアイコンで | キーを離すと消える |
| キー一覧 | ラジアルの周囲、ラジアルが無いツールは S2 の下 | 主要なキーの一覧 | 求めたとき（C を押したまま止める / ? キー）だけ |

- 通知は実行した場所に 1 か所だけ出す。ウィンドウから実行したらステータスバー、シーンから実行したらトースト。
- トーストは Surface1 + Outline、成功・警告・エラーはアイコンの色だけで区別する（背景を塗らない）。
- 説明文を常設しない。案内はツールチップ → 修飾キーのバッジ → 迷ったときのヒント → キー一覧の順に、必要な人にだけ出す（MaskMakerV4 §2.6.3）。

### S5 シーン描画の色と線（Handles）

Handles は USS の変数を読めないので、`colors.json` から作った C# 定数 `DennokoSceneColors` を配る。

| 用途 | 色 | 由来 | 今の色 |
| --- | --- | --- | --- |
| ホバー（クリックで足す） | `#ffffff` 不透明度 0.9 の縁 | accent | MaskMakerV4 白縁 / MeshEditor 黄 / MeshSplitter・HairChimera 橙 |
| ホバー（クリックで外す） | `#ff6b6b` の縁 | semantic-error-text | MaskMakerV4 赤縁 |
| 選択済み | `#64b5f6` 塗り 0.35 + 縁 0.9 | selection-border | MeshSplitter・HairChimera `#9dd2ff` |
| ミラー側 | 本体と同じ色の点線（`Handles.DrawDottedLine` / 不透明度 0.5） | — | MeshEditor のピンク |
| ブラシ円 | 白 0.8 の実線（中心の半径）+ 白 0.3（減衰の外側） | accent | MeshEditor 水色 / 黄 |
| 影響度 | selection 色 0.25（弱）→ warning 色 0.9（強）のグラデーション | selection → warning | MeshEditor 青 → 赤 |
| 注意（対象外・壊れた面） | `#ffb74d` | semantic-warning | 各自 |

- シーンの背景は明るいことも暗いこともある（Skybox・衣装の色）ので、線は **黒 0.5 の外線 + 色の内線** の 2 重にして、どの背景でも見えるようにする。
- 太さは 2px（ホバー・選択の縁）と 1px（補助線）の 2 種類。`EditorGUIUtility.pixelsPerPoint` を掛けて、高 DPI でも細くならないようにする。
- 色だけで意味を伝えない。「外す」予告は赤に加えて縁を点線にする。

### S6 情報オーバーレイ

HowManyPolygons のように、作業とは関係なく常に見せたい読み取り専用の表示。

- `ITransientOverlay` を付けない普通の `Overlay` にし、表示 / 非表示はユーザーが Overlay メニューで決める。
- 中身は大きい数値 1 つ + 補足 1 行。段階の色は semantic（success / warning / error-text）を文字色にだけ使う。
- クリックしても何も起きない（操作を置かない）。設定はウィンドウ側か Preferences に置く。

### 3.4 セッション規約（編集モードの約束）

シーンで何かを編集する「編集モード」を持つツールは、次の約束を守る。共通処理は `DennokoSceneSession` にまとめる。

| 項目 | 約束 |
| --- | --- |
| 開始 | ウィンドウ / Inspector の主ボタン、Hierarchy の右クリックから。シーンに開始ボタンを出さない |
| 終了 | Esc（選択があればまず選択を解除し、何も無ければ終了）、S2 の ✕、B7 の「終了」。どれも同じ処理 |
| 自動終了 | Play モードの開始、シーンの切替、再コンパイルの前、対象の削除、ウィンドウを閉じたとき。作業は保存してから終わる。再コンパイル・Play から戻ったら同じ対象で再開してよい |
| 同時に 1 つ | dennokoworks の編集セッションは同時に 1 つだけ。別のツールで開始したら、前のセッションを終了してから始める |
| 作業中だけ有効 | S1 / S2 は `ITransientOverlay` で作業中だけ出す。ショートカットはタグ付きで登録し、作業中だけ `RegisterTag` する |
| Unity のハンドル | 作業中は移動 / 回転ツールのハンドルを隠し（`Tools.hidden`）、終了で元に戻す |
| カメラ操作 | Alt + ドラッグ・中ボタン・右ボタンのドラッグは消費しない。視点を動かして誤って編集しないようにする |
| 選択の保護 | 作業中は Hierarchy の選択を変えても対象を変えない（切り替えは B1 / B7 の ▼ から） |
| Undo | 編集は Unity の Undo に積む。スライダーは 1 ドラッグ 1 段 |
| 表示 | 作業中はウィンドウ / Inspector に B7、シーンに S2 のセッション行（S2 が無いツールは S1 の右端に ● を出す） |

```csharp
var session = DennokoSceneSession.Begin(new DennokoSceneSession.Options
{
    ToolId      = "DenMeshEditor",
    DisplayName = "Mesh Editor",
    Target      = component.gameObject,
    ShortcutTag = "Dennokoworks.DenMeshEditor.Editing",
    OnEnd       = reason => SaveAndCleanup(reason),  // User / Escape / PlayMode / Reload / SceneChanged / TargetLost / Replaced
});
session.HandleEscape = () => _hasSelection ? ClearSelection() : false;  // true を返したら終了しない
DennokoSceneSession.ActiveChanged += RefreshBanner;                      // B7 と S2 のセッション行を更新
```

## 6. 導入ステップと検証計画

部品案と同じく「UI Design Test で実装 → Unity で確認 → スキルへ反映」の順で進める。部品案のステップ 1〜4（トップバー〜カード内部品）と並行してよい。

1. **スキルの分岐を解消**：MaskMakerV4 内のスキルにだけある SceneView 一式（sceneview-guide.md・assets/SceneView/）を UI_Design 側へ取り込む。
2. **S2 + S5 + セッション規約**：UI Design Test にシーン操作 UI のデモ（メニューから開始するダミーの編集セッション）を作り、DennokoMeshEditor に先行適用 → コードがほぼ同じ DennokoNormalEditor / DenLattice へ展開。
3. **B7 作業中バナーと P5 の Inspector 雛形**：DennokoMeshEditor の Inspector で確認。
4. **ブロック**：B1 → B2 → B4 → B3 → B5 → B6 の順（使うツールが多いものから）。
5. **パターンの雛形**：P1 → P3 → P2 → P4 → P5。UI Design Test に「Patterns」タブを作り、パターンごとの見本を並べる。
6. **S5 の色をクリック選択のツールへ**：MeshSplitter / HairChimera / CableGenerator。
7. **MaskMakerV4 の `mm-` クラスを `dennoko-` に置き換え**（`mm-capsule` → `dennoko-capsule` など。見た目は変わらない）。

シーン操作 UI で確認すること：

- [ ] Light / Dark どちらのエディタテーマでも、Overlay の見出し・枠（Unity 側が描く部分）とテーマの中身が浮かないか
- [ ] SceneView を 2 つ開いたとき、S1 / S2 が両方に出ても操作が食い違わないか
- [ ] 再コンパイル・Play モード・シーン切替で自動終了し、ハンドル・タグ・HUD が残らないか
- [ ] 別ツールのセッションを開始したとき、前のセッションが保存されて終わるか
- [ ] スライダーの 1 ドラッグが Undo 1 段になるか。シーン側のホイールで変えた値がパネルに出るか
- [ ] 表示スケール 150% / 200% でカーソル脇の表示とラジアルの位置がずれないか
- [ ] 背の低い SceneView でパネルが画面外にはみ出さないか
- [ ] 明るい背景・暗い背景どちらでもシーンの線（2 重線）が見えるか
